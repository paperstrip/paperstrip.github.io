# Deux familles de robots d'IA, deux traitements.
#
# Bloques : ceux qui aspirent pour entrainer des modeles. Ils ne renvoient
# ni visite ni citation, le site n'a rien a y gagner.
#
# Laisses passer : ceux qui vont chercher une page pour repondre a quelqu'un
# et la citent (OAI-SearchBot, ChatGPT-User, Claude-User, Claude-SearchBot,
# PerplexityBot). Les bloquer reviendrait a se retirer des reponses
# generatives, ce qui irait contre le travail de referencement fait ici.
#
# La regle qui decide : ne bloquer un fournisseur que s'il publie un jeton
# SEPARE pour ses reponses. Sinon on se retire de ses reponses en croyant
# ne refuser que l'entrainement.
#
#   OpenAI    GPTBot (entrainement) / OAI-SearchBot / ChatGPT-User   separe
#   Anthropic ClaudeBot / Claude-User / Claude-SearchBot             separe
#   Apple     Applebot-Extended (entrainement) / Applebot (Siri)     separe
#   Google    Google-Extended : PAS de jeton separe                  melange
#
# Google-Extended ne se bloque donc pas. Il ne touche effectivement ni a
# l'indexation ni au classement dans Google Search, mais il pilote aussi le
# grounding de Gemini, c'est-a-dire sa capacite a lire la page pour repondre.
# Constate en direct : Gemini refusait d'ouvrir le site tant qu'il figurait
# dans la liste ci-dessous.
#
# Un robot suit le groupe qui le nomme, et celui-la seulement : ceux qui ne
# sont pas listes ci-dessous relevent de User-agent: * et passent.
#
# Rappel : robots.txt est declaratif. Il est respecte par les robots serieux
# et ignore par les aspirateurs. Sans serveur, GitHub Pages ne permet aucun
# blocage reel.
